## About The Project

[![Stock Barang][stock-barang]](https://github.com/FanX0/stock-barang)

Stock management dashboard

- There is an authentication process
- Incoming Goods module records item name, quantity, description, add edit delete
- Outgoing Goods module records the name of the item, recipient, add edit delete

On the main page, display the Stock Module recording the name of the item, quantity, description, add edit delete, export to excel, expoort to pdf

<!-- GETTING STARTED -->

## Getting Started

### Installation

1. If using xampp place project to htdocs or If using laragon place project to www
2. Clone the repo
   ```sh
   git clone https://github.com/FanX0/stock-barang
   ```
3. Take the db from the db_stockbarang file at the root of the project and import it into the database.
4. Acces the project

   ```sh
   http://localhost/dashboard-stock-barang/masuk.php
   ```
